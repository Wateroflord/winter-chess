# Шахматы

Играй против бота от новичка до полной силы Stockfish за белых или чёрных, вдвоём на одном устройстве с часами, решай задачи (мат в 1–3 хода, вилки, связки), проходи уроки и смотри разбор партии с ошибками и лучшими ходами.

Задачи — из открытой базы Lichess (CC0).

## Установка

Приложение семейства **Winter Hub** (Android + Windows). Удобнее всего ставить и обновлять через Winter Hub, либо скачать файл из раздела **Releases**: `Winter-Chess.apk` для телефона, `Winter-Chess-Setup.exe` для ПК.

## Как устроено

Flutter (Dart). lib/engine.dart — Stockfish и встроенный бот, lib/lessons.dart — уроки, assets/puzzles.json — задачи.

Сборку делает GitHub Actions при каждом изменении в `main`: анализ кода, тесты (`test/`), сборка APK и установщика для Windows, подпись постоянным ключом (общие скрипты в `winter-hub/ci`) и публикация в Releases.
